# MeloSpace Product Spec
**Purpose:** make music learning and instrument access affordable via a seated, hands-first VR studio.
**Users:** beginners first; later intermediate players and creators.
**Journey (MVP):** Studio -> pick piano -> Learn -> beginner lesson -> hear reference -> play highlighted notes -> deterministic score -> tutor coaching.
**MVP:** one-octave piano (C4-C5), sound, 3 lessons (first: C4 D4 E4 F4 G4), local scoring, local progress, tool-calling tutor.
**Future:** sampled audio, voice tutor, accounts (Firebase), guitar/bass/drums, Create mode, virtual band.
**Functional:** 13 keys with stable ids and MIDI; note-on/off; no stuck notes; data-driven lessons; scoring independent of Gemini; guest mode needs no network.
**Non-functional:** seated use, no controller requirement, no locomotion, secrets server-side only, core works if Gemini is down.
